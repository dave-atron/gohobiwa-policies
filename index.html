Gohobiwa

A task tracker that pays you more for the things you least want to do.

Every task gets points based on how hard it is, how early you finish it, and how unpleasant it is. Easy, fun tasks pay little. Dreaded ones pay a lot. Late tasks still count.

Invitation only

Gohobiwa is a personal project. Each person who uses it gets a private instance that I run for them. It is not a public service and has no public sign-up.

Google Calendar

If you choose to connect Google Calendar, Gohobiwa uses your primary calendar to see when you are busy and to add the task blocks you approve. It does nothing else with your calendar. Details are in the privacy policy, including how to disconnect.
